# 🍢 Turkish Zaika Restaurant — Digital Menu

A high-performance, mobile-first contactless digital menu built for **Turkish Zaika Restaurant, Solapur**.

Live URL Target: **`https://turkishzaika.linkal.in`**

---

## ✨ Features

- ⚡ **Zero-Dependency Standalone Build**: Pure HTML5, CSS3, and Vanilla JavaScript. Loads instantly in any browser.
- 🎨 **Solapur & Turkish Theme**: Premium dark onyx & warm amber palette with smooth transitions.
- 🎬 **Animated Entrance**: Welcome screen ("Welcome to Turkish Zaika Restaurant • Solapur") with loading progress indicator.
- 🍽️ **Dish Details Modal**: Click any dish to see a full photo, detailed description, tags, and **portion/serving size** (e.g. *Serves 2-3 Persons*).
- 🚫 **No WhatsApp Order CTA**: Clean, focused digital menu design strictly for table browsing and contactless dining.
- 📱 **Table QR Code Generator & 1-Click Download**:
  - Generates high-res QR code pointing directly to `https://turkishzaika.linkal.in`.
  - 1-click **Download Printable QR Card (PNG)** formatted with restaurant name and instructions for printing table stands.
- 🔗 **Share Menu**: Native Web Share API integration (WhatsApp, SMS, Copy link).
- 🚀 **Linkal Marketing Header**: Clean, non-intrusive banner promoting Linkal digital menu builder (`linkal.in`).
